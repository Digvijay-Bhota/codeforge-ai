# docs/decisions/

This directory contains Architectural Decision Records (ADRs) for CodeForge AI.

## Format

Each ADR is a single markdown file named `NNN-short-title.md` containing:

- **Status** — Proposed / Accepted / Deprecated / Superseded
- **Context** — What problem are we solving?
- **Decision** — What did we decide?
- **Consequences** — What are the trade-offs?
